
# To-Do List Android Application

An Android application developed using Kotlin and XML
for creating and managing daily tasks.

## Technologies Used
- Kotlin
- Android Studio
- XML
- RecyclerView
- SharedPreferences
- JSON

## Features
- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Track pending and completed tasks
- Save tasks locally using SharedPreferences

## Architecture
- MainActivity: Application logic
- Task: Task data model
- TaskAdapter: RecyclerView adapter
- SharedPrefManager: Local data storage

## Installation
1. Clone this repository.
2. Open the project in Android Studio.
3. Sync Gradle.
4. Connect an Android device.
5. Run the application.
